# NIMS 제3장 정리노트

**지휘 및 조정(Command and Coordination)** — 현장지휘, 대응 지원, 정책 판단과 공보체계를 함께 이해하기 위한 한국어 학습 정리입니다.

## 학습 웹페이지

이 저장소 루트의 `index.html`은 원문을 충실히 정리하고 반복해서 찾아보는 한 페이지 정리노트입니다. 발표용 PPT는 별도로 제작합니다. 챕터 목차, 모바일용 표 구성, 원문 그림 확대, 복습 정답 열기를 제공합니다.

Vercel에서 이 저장소를 Import하고 정적 사이트로 배포할 수 있습니다. 배포할 때 Framework Preset은 Other, Root Directory는 저장소 루트로 둡니다. 별도의 설치·빌드 명령 없이 HTML·CSS·JavaScript와 이미지 파일로 동작합니다. 현재 Vercel 배포 주소는 아직 없습니다.

- 웹페이지 파일: [index.html](index.html), [styles.css](styles.css), [app.js](app.js)
- 제작 기준: [BUILD_PROMPT.md](BUILD_PROMPT.md)

## 읽는 순서

1. [제3장 학습 노트](chapter3.md): 관리특성 14개, 주요 조직·직책·시설, 원문 그림 3~10 전체 8개
2. [번역 기준과 FEMA 보충 용어](terms.md): Incident 번역, 4Cs, 조정·협업의 정의와 적용 맥락
3. [복습 정리](study-guide.md): 설명 순서, 개념 비교, 예외 조건, 이해도 점검

그림은 학습 노트의 해당 설명 옆에서 볼 수 있습니다. GitHub에서 그림을 클릭하면 큰 이미지로 열립니다.

## 자료와 검증 범위

- 기준 자료: FEMA, *National Incident Management System*, Chapter III: Command and Coordination, 영문 인쇄 pp.19–49 발췌본.
- 원문 개념·조건·쪽수를 직접 대조하고 별도 읽기 전용 검토를 반영했습니다.
- 번역본 정밀 교열과 한국 긴급구조통제단 제도 비교는 미검증입니다.
- 학습 질문과 복습 순서는 원문을 바탕으로 만든 학습용 제안입니다.
- 그림의 영어 명칭과 조직 관계는 원문 그대로이며 한국어 제목·설명은 학습용입니다. 원문 그림의 출처는 FEMA NIMS이며, 새로 만든 원본 그림으로 표시하지 않습니다.

## 핵심 질문

여러 기관이 공동 목표를 정하면서 각 구성원은 한 명에게 보고하도록 하려면 지휘와 조정을 어떻게 연결해야 할까요?

## 용어 기준

일반 개념어 Incident는 사고로 통일합니다. 계획된 행사·비상상황·재난도 포함하며 사고지휘체계·사고지휘관·현장지휘소는 유지합니다. 웹페이지는 10개 챕터로 구성되며 FEMA 보충 교육자료의 용어와 제3장 원문을 구분합니다. 한국어는 학습용 번역입니다.
