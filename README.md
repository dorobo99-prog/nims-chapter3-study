# 현장지휘체계 학습 노트

[전체 목차](https://dadem-nims-study.vercel.app/) · [제1장](https://dadem-nims-study.vercel.app/chapters/01/) · [제3장](https://dadem-nims-study.vercel.app/chapters/03/) · [제4장](https://dadem-nims-study.vercel.app/chapters/04/) · [제6장 용어집](https://dadem-nims-study.vercel.app/chapters/06/) · [부록 A](https://dadem-nims-study.vercel.app/appendices/a/) · [부록 B](https://dadem-nims-study.vercel.app/appendices/b/)

제1~8장을 연결할 학습 목차입니다. 현재 제1장 NIMS의 기초와 개념, 제3장 지휘 및 조정, 제4장 통신 및 정보관리, 제6장 용어집을 제공합니다. 그 밖의 장은 자료 등록 후 제목과 내용을 연결합니다.

## 학습 자료

- [제3장 원문 기반 정리](chapter3.md) · [용어](terms.md) · [지휘체계 비교](command-comparison.md) · [참모 역할](staff-roles.md) · [복습](study-guide.md) · [연구 연결](q-research.md)
- [제4장 원문 기반 정리](chapter4.md)

제3·4장 기준은 FEMA NIMS 제3판(2017)의 인쇄 pp.19–49, pp.50–59입니다. 한국어 설명과 비교표는 학습용 정리입니다. 원문 그림과 USNG 설명 상자를 이미지 그대로 사용하며, 제4장에는 번호가 붙은 원문 그림·표가 없습니다.

제6장은 제공된 VI. Glossary의 용어 142개와 VII. List of Abbreviations의 약어 26개(AHJ–ISM)를 영문·한국어 대역 그대로 수록합니다. 영한 검색과 알파벳 탐색을 제공합니다. 쪽수61–72는 제공 문서의 표시이며, 공식 PDF와 별도 전수 대조한 결과나 전체 원전의 완결 약어 목록으로 주장하지 않습니다. 제3·4장과의 번역 표기 차이를 안내합니다.

제1장은 사용자 제공 심층 서브노트의 본문14절·표20개·HTML/CSS 개념도·참고문헌78항목을 수록합니다. 교재 요지와 교재 외 자료·학습 해석·가설·확인 필요를 구별하며, 모든 참고문헌이나 현행 법령을 독립 검증한 원전 대역본은 아닙니다. 표의 내용·행열·주석과 개념도를 보존하고 전체/핵심 보기·절별 탐색을 제공합니다.

부록 A·B는 사용자 제공 학습 HTML과 내장 PNG를 보존한 페이지입니다. A는 10개 ICS 탭·그림12개·표3종(17개 PNG), B는 EOC3모델·조직도3개입니다. 한국어 HTML 요약표20개와 복습15문항을 함께 수록합니다. 이미지20개는 원래 바이트 그대로 사용하며, 일부 제공 이미지의 잘린 주변부를 임의로 복원하지 않았습니다. 공식 PDF 전체·쪽수 대응의 별도 검증과 구별합니다.

## 사이트 구성

정적 HTML·CSS·JavaScript로 동작하며 별도 설치나 빌드가 필요하지 않습니다. Vercel 프로젝트 `dadem-nims-study`가 이 저장소의 main 브랜치를 자동 배포합니다.

- 전체 목차: index.html
- 장별 페이지: chapters/01/index.html, chapters/03/index.html, chapters/04/index.html, chapters/06/index.html
- 부록 페이지: appendices/a/index.html, appendices/b/index.html
- 기존 제3장 Markdown·이미지 경로 유지
- 기존 루트의 제3장 섹션 링크(index.html#ics 등)는 제3장 해당 위치로 연결

## 검증 경계

원문 직접 판독과 읽기 전용 재검토를 반영했습니다. EEI 14항목과 수집 방법 8가지는 예시, 6개 데이터 처리 항목은 표준 요소, IAP 작전기간 12~24시간은 통상 범위입니다. 평문은 암호화 금지와 구별합니다. 한국 현행 제도·미제공 외부 양식은 확정하지 않습니다.
